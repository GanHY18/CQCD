# Chongqing–Chengdu–Jiuzhaigou Family Trip

A simple mobile-friendly itinerary website for 14 travellers, 6–13 March 2027.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — day-by-day itinerary and interactive checklist

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `chongqing-chengdu-travel`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish. The site address will be shown on the Pages settings screen.

## Important travel notes
- The Jiuzhaigou day trip is planned as high-speed rail from Chengdu East to Huanglongjiuzhai, then private charter transfer.
- Train times are placeholders and are not confirmed.
- Verify both rail legs, park operating conditions, road conditions and realistic time inside the park before booking the charter.
- If the return train timing is unsuitable, change to an overnight Jiuzhaigou trip rather than forcing an unsafe or impractical day trip.
- Hotel names and bookings are intentionally left open because accommodation has not yet been selected.
- All transport and attraction details should be rechecked closer to March 2027.
